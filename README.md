# TokenLab Vercel AI SDK Example

Minimal Node example using the TokenLab AI SDK provider package.

This example targets AI SDK 7 and Node.js 22 or newer.

## Quickstart

```bash
npm install
cp .env.example .env
TOKENLAB_API_KEY=sk-your-tokenlab-key npm start
```
